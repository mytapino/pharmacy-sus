# แบบสอบถาม SUS (System Usability Scale) สำหรับ Google Form

อ้างอิง: Brooke, J. (1996). *SUS: A "quick and dirty" usability scale.*

## ตั้งค่าในฟอร์ม

- ทุกข้อใช้ชนิดคำถาม **Linear scale (สเกลเชิงเส้น) 1 – 5** และเปิด **Required**
  - 1 = ไม่เห็นด้วยอย่างยิ่ง
  - 5 = เห็นด้วยอย่างยิ่ง
- **ห้ามกลับทิศสเกล** ทุกข้อต้องเรียง 1 → 5 จาก "ไม่เห็นด้วย" ไป "เห็นด้วย"
- **ห้ามสลับลำดับข้อ** และห้ามเปิด "Shuffle question order" เพราะข้อคี่เป็นเชิงบวกและข้อคู่เป็นเชิงลบ สลับกันตามสูตรคิดคะแนน
- **ห้ามเปลี่ยนข้อเชิงลบให้เป็นเชิงบวก** ถ้าเปลี่ยน สูตรคิดคะแนนจะใช้ไม่ได้
- ควรให้ผู้ทดสอบตอบ **ทันทีหลังใช้งานระบบ** และตอบตามความรู้สึกแรกโดยไม่ต้องคิดนาน

**คำอธิบายฟอร์ม (วางใน Description):**
> กรุณาตอบหลังจากทดลองใช้ "ระบบร้านขายยา" เสร็จแล้ว ให้เลือกระดับที่ตรงกับความรู้สึกของคุณมากที่สุด ไม่ต้องคิดนาน หากข้อใดไม่แน่ใจให้เลือก 3

## คำถาม 10 ข้อ (ลำดับห้ามเปลี่ยน)

| ข้อ | ทิศ | คำถาม (ไทย) | ต้นฉบับ (English) |
|---|---|---|---|
| 1 | ➕ บวก | ฉันคิดว่าฉันอยากใช้ระบบนี้บ่อย ๆ | I think that I would like to use this system frequently. |
| 2 | ➖ ลบ | ฉันพบว่าระบบนี้ซับซ้อนเกินความจำเป็น | I found the system unnecessarily complex. |
| 3 | ➕ บวก | ฉันคิดว่าระบบนี้ใช้งานง่าย | I thought the system was easy to use. |
| 4 | ➖ ลบ | ฉันคิดว่าฉันต้องได้รับความช่วยเหลือจากผู้ที่มีความรู้ด้านเทคนิคจึงจะใช้ระบบนี้ได้ | I think that I would need the support of a technical person to be able to use this system. |
| 5 | ➕ บวก | ฉันพบว่าฟังก์ชันต่าง ๆ ในระบบนี้เชื่อมโยงกันได้เป็นอย่างดี | I found the various functions in this system were well integrated. |
| 6 | ➖ ลบ | ฉันคิดว่าระบบนี้มีความไม่สอดคล้องกันมากเกินไป | I thought there was too much inconsistency in this system. |
| 7 | ➕ บวก | ฉันคิดว่าคนส่วนใหญ่จะเรียนรู้การใช้ระบบนี้ได้อย่างรวดเร็ว | I would imagine that most people would learn to use this system very quickly. |
| 8 | ➖ ลบ | ฉันพบว่าระบบนี้ใช้งานยุ่งยากและเทอะทะมาก | I found the system very cumbersome to use. |
| 9 | ➕ บวก | ฉันรู้สึกมั่นใจมากในการใช้ระบบนี้ | I felt very confident using the system. |
| 10 | ➖ ลบ | ฉันต้องเรียนรู้หลายอย่างก่อนจึงจะเริ่มใช้ระบบนี้ได้ | I needed to learn a lot of things before I could get going with this system. |

ใน Google Form ไม่ต้องใส่คอลัมน์ "ทิศ" ให้ผู้ทดสอบเห็น ตารางนี้มีไว้ให้ผู้วิจัยใช้คิดคะแนนเท่านั้น

## วิธีคิดคะแนน

1. **ข้อคี่ (1, 3, 5, 7, 9):** คะแนน = คำตอบ − 1
2. **ข้อคู่ (2, 4, 6, 8, 10):** คะแนน = 5 − คำตอบ
3. รวมคะแนนทั้ง 10 ข้อ (ได้ 0–40) แล้ว **คูณ 2.5** จะได้คะแนน SUS ช่วง **0–100**

> คะแนน SUS **ไม่ใช่เปอร์เซ็นต์** และไม่ควรแปลผลคะแนนรายข้อ ให้ใช้คะแนนรวมเท่านั้น

**สูตร Google Sheets** (ชีตคำตอบ: A = Timestamp, B–K = ข้อ 1–10) ใส่ที่ L2 แล้วลากลง:

```
=2.5*((B2-1)+(5-C2)+(D2-1)+(5-E2)+(F2-1)+(5-G2)+(H2-1)+(5-I2)+(J2-1)+(5-K2))
```

ถ้ามีคำถามข้อมูลทั่วไป (ชื่อ อายุ ฯลฯ) อยู่ก่อนชุด SUS คอลัมน์จะเลื่อนไป ให้ปรับตัวอักษรคอลัมน์ในสูตรให้ตรง

ค่าเฉลี่ยของระบบ = `AVERAGE` ของคอลัมน์ L

## การแปลผล (Bangor, Kortum & Miller, 2009; Sauro, 2011)

| คะแนน SUS | ระดับคำ (Adjective) | ความหมาย |
|---|---|---|
| ≥ 85 | Excellent | ดีเยี่ยม |
| 71 – 84 | Good | ดี |
| 68 | — | **ค่าเฉลี่ยกลาง** (ประมาณ percentile ที่ 50) |
| 51 – 70 | OK | พอใช้ / ควรปรับปรุง |
| ≤ 50 | Poor | ไม่ผ่าน ต้องปรับปรุงมาก |

เกณฑ์แบ่งช่วงต่างกันเล็กน้อยในแต่ละแหล่ง ตอนเขียนรายงานให้อ้างแหล่งที่ใช้ และรายงานค่าเฉลี่ย ค่า SD และจำนวนผู้ทดสอบ (n) คู่กันเสมอ
